### Product name — 7 znaků

### Description — 2010 / 10000 znaků
Dirwise — быстрый файловый менеджер для Windows, которым удобно управлять с клавиатуры.

Просматривайте глубокие деревья папок в режиме колонок с панелью предпросмотра или переключитесь на значки и список. Открывайте папки во вкладках — у каждой своя история, вид и сортировка. Разделите окно на две панели и копируйте или перемещайте файлы между ними клавишами F5 / F6.

Ctrl+K открывает палитру команд: переход к быстрому доступу, недавним папкам и вкладкам, запуск любого действия или ввод пути. Пробел открывает мгновенный предпросмотр — изображения, PDF, видео, аудио, текст, исходный код и Markdown.

Dirwise работает с настоящим буфером обмена Windows, поэтому файлы можно копировать в другие приложения и из них, например в Outlook или браузер. Перетаскивание работает в обе стороны: перетащите файлы из других окон или с рабочего стола внутрь, а наружу — в другие окна, на рабочий стол, в браузер для загрузки, в Discord или в письмо. Кнопка New создаёт папки, текстовые документы и любые типы файлов из меню «Создать» Windows. Отмена и повтор охватывают последние 50 операций, включая удаление (файлы восстанавливаются из Корзины). Корзина находится прямо на боковой панели: восстанавливайте элементы, удаляйте их навсегда или очищайте её. В защищённых местах, например в корне диска C:, выберите Continue as Administrator и подтвердите запрос Windows.

По умолчанию используется полупрозрачный стеклянный вид. Включите Transparency в меню More → Appearance, и рабочий стол и другие окна будут просвечивать сквозь приложение с размытием, как Acrylic в Windows 11 (Windows 11 22H2 и новее). Силу эффекта можно выбрать из трёх уровней.

Окно имеет стандартную строку заголовка Windows 11 с макетами прикрепления (Snap Layouts). Светлая и тёмная темы следуют настройкам Windows. Интерфейс доступен на английском и чешском языках.

Конфиденциальность: без телеметрии, без учётной записи, без рекламы. Версия из Microsoft Store сама не выполняет никаких сетевых запросов — обновления приходят через Store.

미리 보기 창이 있는 열 보기로 깊은 폴더 구조를 탐색하거나, 아이콘 보기와 목록 보기로 전환하세요. 폴더를 탭으로 열면 탭마다 기록, 보기, 정렬이 따로 유지됩니다. 창을 두 패널로 나누고 F5 / F6으로 패널 사이에서 파일을 복사하거나 이동할 수 있습니다.

Ctrl+K를 누르면 명령 팔레트가 열립니다. 빠른 액세스, 최근 폴더와 탭으로 이동하고, 원하는 작업을 실행하거나 경로를 입력하세요. 스페이스바를 누르면 이미지, PDF, 동영상, 오디오, 텍스트, 소스 코드, Markdown을 즉시 미리 볼 수 있습니다.

Dirwise는 실제 Windows 클립보드를 사용하므로 Outlook이나 브라우저 같은 다른 앱과 파일을 주고받으며 복사할 수 있습니다. 끌어서 놓기는 양방향으로 동작합니다. 다른 창이나 바탕 화면에서 파일을 끌어 오고, 다른 창, 바탕 화면, 브라우저 업로드, Discord, 이메일로 끌어 놓을 수 있습니다. New 단추로 폴더, 텍스트 문서는 물론 Windows의 새로 만들기 메뉴에 있는 모든 파일 형식을 만들 수 있습니다. 실행 취소와 다시 실행은 삭제를 포함해 최근 50개 작업에 적용됩니다(삭제한 항목은 휴지통에서 복원). 휴지통은 사이드바에 바로 있어 항목을 복원하거나, 영구 삭제하거나, 휴지통을 비울 수 있습니다. C: 드라이브 루트처럼 보호된 위치에서는 Continue as Administrator를 선택하고 Windows 확인 창에서 승인하세요.

기본 모양은 반투명 유리 스타일입니다. More → Appearance에서 Transparency를 켜면 바탕 화면과 다른 창이 Windows 11 Acrylic처럼 흐리게 앱 뒤로 비쳐 보입니다(Windows 11 22H2 이상). 강도는 세 단계 중에서 고를 수 있습니다.

창에는 스냅 레이아웃(Snap Layouts)을 지원하는 표준 Windows 11 제목 표시줄이 있습니다. 밝은 모드와 어두운 모드는 Windows 설정을 따릅니다. 인터페이스는 영어와 체코어로 제공됩니다.

개인정보 보호: 원격 분석 없음, 계정 없음, 광고 없음. Microsoft Store 버전은 자체적으로 네트워크 요청을 전혀 하지 않으며, 업데이트는 Store를 통해 제공됩니다.
